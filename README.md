# Tap Majestic RP

Tap показывает поверх игры иконки телефона и планшета. По иконке телефона открывается Telegram, по иконке планшета — Google. Работает с игрой Majestic Multiplayer, только на Windows.

## Видеоинструкция

https://youtu.be/g34oquAsRt0?si=dl5newBHGgGy8RzQ

## Как установить

1. Открой раздел **Releases** справа на главной странице репозитория.
2. Скачай файл **Tap.zip**.
3. Распакуй архив целиком в любую папку. Не запускай программу прямо из архива.
4. Запусти **Tap.exe** внутри распакованной папки. Папку `_internal` рядом с ним не удаляй.

## Как пользоваться

1. В окне Tap включи нужные галочки: «Планшет (Google)» и «Телефон (Telegram)».
2. Войди в игру.
3. Нажми клавишу с стрелкой:
   - **Вверх** — открыть или закрыть телефон
   - **Вниз** — открыть или закрыть планшет
   - **Вправо** — аварийный сброс, убирает всё с экрана
4. Кликни по появившейся иконке, и откроется браузер.

Телефон открывается только из игры: нажми стрелку вверх, потом кликни по экрану блокировки, и через несколько долей секунды появится иконка.

## Подгонка под свой экран

Если рамка или иконка стоят не в том месте:

1. В окне Tap выбери «Планшет» или «Телефон» и нажми «Включить режим подгонки на экране».
2. Рамку тяни за верхнюю полоску или за края, иконку тяни на место.
3. Размер иконки меняй за тёмный уголок в её правом нижнем углу.
4. Нажми «СОХРАНИТЬ», потом «Перезапустить», чтобы новые настройки принялись.

Настройки хранятся в папке `%APPDATA%\Tap`.

## Запуск из исходников

Нужен Python 3 и библиотеки PyQt6, PyQt6-WebEngine, keyboard и mouse. Запуск: `python app.py`.

Сборка exe: `python -m PyInstaller Tap.spec --noconfirm`.
